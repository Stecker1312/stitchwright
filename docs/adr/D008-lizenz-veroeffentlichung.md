# D008 – GPL-3.0 und Veröffentlichung erst ab v0.1

- Datum: 2026-11-18
- Status: Gültig
- Betrifft: Stitchwright

## Zusammenhang

Das Projekt soll den Markt für Strickschrift-Software öffnen: kostenlos,
offen, lokal. Gleichzeitig soll niemand eine geschlossene Konkurrenz aus dem
Code machen. Das Repository ist zunächst privat, damit Daniel ohne
Erwartungsdruck an einer vorzeigbaren Version arbeiten kann.

## Entscheidung

- Lizenz: **GPL-3.0**.
- Das Repository liegt privat unter `Stecker1312/stitchwright`.
- Veröffentlicht wird erst, wenn der Editor-MVP die Abnahme besteht:
  Chart zeichnen, speichern, laden, SVG exportieren, drucken.
- Vor der Veröffentlichung: README mit Screenshots, Contribution-Hinweise,
  Issue-Vorlagen, keine persönlichen Daten, Tests grün.
- GitHub Pages wird erst zur Veröffentlichung aktiviert.

## Folgen

- Der Code bleibt frei und Verbesserungen fließen zurück.
- Keine kommerzielle Doppelverwertung ohne Offenlegung.
- Bis zur Veröffentlichung kann sich das Format noch ändern; das ist bewusst.

## Alternativen

- MIT: maximal bequem, erlaubt aber geschlossene Forks.
- AGPL: stärker für Web-Dienste, aber für eine lokale App unnötig streng.
- Sofort veröffentlichen: zu früh, unfertige Software verbrennt Vertrauen.
