# D009 – Öffentliche Vorabversion 0.1.0-alpha.1

- Datum: 2026-11-18
- Status: Gültig
- Betrifft: Stitchwright

## Zusammenhang

Der Editor ist benutzbar, die Abnahme im Browser ist erfolgt, und Daniel hat
die Veröffentlichung ausdrücklich freigegeben. Es handelt sich um einen frühen
Stand: Fehler und Änderungen am Dateiformat sind noch möglich.

## Entscheidung

- Das Repository `Stecker1312/stitchwright` wird öffentlich.
- GitHub Pages veröffentlicht die App unter
  `https://stecker1312.github.io/stitchwright/`.
- Die erste Version heißt `0.1.0-alpha.1` und wird als **frühe Vorabversion**
  gekennzeichnet – im README, auf der Projektseite, im Changelog und im
  Release. Die aktuelle Alpha ist `0.5.0-alpha.1`.
- Die Lizenz bleibt GPL-3.0.
- Es gibt kein Support-Versprechen und keine Produktionsgarantie.
- Cloud, Konten, Kollaboration und Telemetrie bleiben ausgeschlossen.

## Folgen

- Fehlerberichte und Beiträge kommen über GitHub Issues und Pull Requests.
- Das Dateiformat bleibt vorerst `strickschrift/1`; Änderungen brauchen eine
  Migration und eine neue Schemaversion.
- Veröffentlichungen werden ab jetzt über SOP-004 vorbereitet.
- Die private Phase ist beendet; der öffentliche Stand ist der aktuelle
  `main`-Branch.

## Alternativen

- Weiter privat: vom Nutzer abgelehnt.
- Sofort als stabile Version: unredlich, der Stand ist eine Alpha.
